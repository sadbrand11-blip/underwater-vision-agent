## 实测核对

- 九个实验核心源码与原冻结哈希、当前源码、归档副本逐字节一致。归档在测试后保存，只能证明与测试前摘要一致，不能冒称测试前已保存副本。
- 最终软件测试：**163 passed in 154.94s**；另有 **31 passed in 6.67s** 的针对性回归。
- 最终六个本地 API 案例保存于 D 盘唯一运行目录 `vision_v040/web_checks/v040_delivery_r1_20261001T062037996659Z/`：曝光单任务、管道、机器人、联合目标、真实校正、全黑停止。六例完成，真实视觉计算，**LLM 请求尝试为 0**。
- API 校正例亮度中位数由 0.105882 变为 0.152941，仍判为不可靠；全黑例没有校正或检测。这些说明程序行为，不能证明识别准确率改善或真实 LLM 的规划能力。
- 审核只读 API/代码/记录；执行者另外检查了实际浏览器页面。浏览器检查不属于审核者的独立验收。
