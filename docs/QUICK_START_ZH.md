# 通用图像 Agent：打开与使用

## 本机双击

本节适用于已配置本机启动器的电脑；新克隆项目请看下方公开版安装。

进入 `D:\CodexData\optical_agent`，双击 **启动通用图像Agent.bat**。原“启动水下图像Agent.bat”仍可打开同一当前版本。

浏览器访问 **http://127.0.0.1:7860/agent**。先点“使用示例”，选择“离线脚本演示”，再点“只检查曝光”或“只识别人”，提交任务。

离线规则演示只验证工具与程序链路；自由中文任务选择已配置的云端模式。安装和启动不会自动调用云端。

可尝试：

- `只检查这张图的曝光。`
- `只识别人和汽车。`
- `检查这张图，必要时校正曝光，然后只识别人，说明结果是否可靠。`
- `比较校正前后。`

输入限8位JPEG/PNG，32MiB、1600万像素以内。程序处理EXIF方向并转RGB，原图保留。目标为COCO80类，二维码、管道等列表外目标明确提示不支持。

## 怎样理解结果

任务完成、曝光质量和视觉可靠性分别判断。无检测权重仍可评估/校正曝光；检测会报不可用，不显示虚构的0个目标。高分框仍是候选；没有独立校准依据不能自动接受。开发集未证明默认校正有益时采用原图，仍可请求并查看校正候选。

计划、候选、热图、引用、记忆和调用记录可展开。高级设置保留RAG、native/LangGraph与调度对照；切换固定配置须创建新会话。

通用偏好与摘要使用独立数据库。旧水下类别和历史不参与当前分析；显示偏好可只读迁移。全部下载、缓存、权重、日志和评测保存在D盘。

## 公开版安装

```powershell
python -m pip install -r requirements-demo.txt
python run_demo.py
```

默认真实运行曝光工具，无需Torch/密钥/权重。需要检测时：

```powershell
python -m pip install -r requirements-detector.txt
python run_demo.py --with-detector
```

官方COCO权重下载到D盘并验证完整SHA256。轻量入口为 `/showcase`；对话入口为 `/agent`。没有本地真实示例时，页面会明确显示程序生成的曝光测试图，可自行上传普通照片。

启动失败时查看 `D:\CodexData\optical_agent\langgraph\runs\server.err.log`，发送错误截图即可，勿发送.env或密钥。
