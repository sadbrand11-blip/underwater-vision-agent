# 公开版本操作指南

## 你可以先运行什么

默认演示不需要 DeepSeek 密钥、GPU 或检测权重。它实际计算曝光指标并生成
有界校正图；调度是明确标注的离线规则，不代表云端大模型能力。

在 PowerShell 中依次执行 README 的 Quick Start 命令，然后打开
`http://127.0.0.1:7860/showcase`。先点 **Assess exposure only**（只检查曝光），
再点 **Correct exposure only**（只校正曝光），观察工具记录与原图、候选图。
数据与缓存默认保存在 `D:\CodexData\optical_agent\public`。

另一个项目占用 7860 时，加 `--port 7861`，打开对应的新地址。
不要关闭你原来正在运行的私有开发服务。

## 开启真实检测

按 README 的检测安装命令安装 CPU Torch，然后用 `--with-detector` 启动。
首次下载约 76 MB 的公开 SODD 权重，校验大小与 SHA256 后才加载。
没有权重时，检测会明确报不可用，不会把缺失模型解释为没有目标。

选择 **Assess, correct if needed, detect pipes & verify**。该预设只保留
两类管道框。亮度乘 0.6 和全黑输入是模拟扰动，不是真实相机重拍。
“不可靠”可以是正确完成的任务；校正后框变多不能证明准确率提高。

## 中文自由对话与云端模式

打开 `/agent` 可使用原有中文工作台、native 默认运行器、长期记忆与知识检索。
云端模式须由你明确选择。将 `.env.example` 复制为 `.env`，仅在电脑本地填密钥，
重启后再选云端。不要上传密钥、记忆数据库或完整聊天记录。

历史检索和正式 Agent Eval 成绩属于各自冻结版本。公开知识库已重新编号并
默认使用 TF-IDF，不能直接沿用旧 C1 分数为新库背书。详见 EVALUATION.md。

## 优化思路

本次主要加强展示与可复现性：把开发历史移入文档，首页突出架构、真实执行和
有限范围内的成绩；将曝光演示与可选检测依赖分开；权重独立发布；公开副本与
私有数据、长期记忆和实验索引隔离。视觉算法与原有可靠性保护仍沿用现有实现。
