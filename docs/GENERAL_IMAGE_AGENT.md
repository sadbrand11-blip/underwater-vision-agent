# 0.6.0 通用自然照片能力与架构

日常配置：`general_rgb_v1`；COCO80闭集；8位JPEG/PNG。已发布的水下版本通过原标签及提交归档，不作为本版支持范围或成绩。

## 工具闭环

图片规范化 → 固定目标契约 → 简短计划 → 工具执行 → 真实观察 → 决策/修订 → 程序完成校验。

- 质量：整图、局部网格与实际目标框内指标；“疑似剪切”属于可观察风险，不是物理曝光真值。
- 校正：原图、bounded Gamma、Gamma/CLAHE有界局部方法；每种只生成一次，不增强候选。
- 检测：官方Faster R-CNN MobileNetV3 320 COCO权重，完整91槽预测头，保留官方category_id，实际支持80类；N/A和背景不进入目标清单。
- 可靠性：质量、候选稳定性、独立校准分层；非可靠结果的所有框均保留为tentative/candidate，不继续标为accepted。
- 采用策略：开发集固定门槛选出的默认策略独立绑定模型、类别和数据；保留原图策略可正确完成条件任务。显式校正、比较可查看候选，候选增多不证明精度提高。
- 校准：仅校准分组、未校正COCO原图拟合；候选变换与新域没有自动获得相同可靠性保证。模型/类别/预处理/输入作用域不匹配时降级为未校准。

## 工程隔离

native保持原生循环，LangGraph保持实际图节点；共享请求、观察、预算、报告和收尾。每回合10次模型请求、12工具、180秒与两次结果纠错继续有效。离线规则不是LLM能力验证。

新通用RAG为`general-natural-v1`，默认TF-IDF；本地Embedding/Hybrid使用独立索引，缺少时明示不可用。知识引用只能来自真实检索，旧C0/C1冻结语料及成绩不变。

通用长期记忆位于`memory/general_rgb_v1.sqlite3`，默认关注全部当前支持类别，版本身份绑定模型、类别、预处理与校准。旧类别/历史不迁入当前证据。

MCP默认同一通用检测器，仍恰好三个工具：assess_image_quality、generate_exposure_candidate、detect_objects。图片编号与网页隔离，协议输出不含普通日志。

API保留`/api/chat`提交方式；新增`/api/capabilities`类别与范围清单，结果带profile/ontology/model/calibration版本。曝光会话不要求检测器可用。旧水下实验选项从日常界面归档，明确请求已归档实验返回可理解错误。

## 使用边界

普通照片内部规则通过不等于任意场景识别正确。不开启相机控制、人工复核队列或生成式纹理恢复；医学、遥感、工业微缺陷与开放词汇目标须另设模型及验收。
