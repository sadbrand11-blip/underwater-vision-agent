# 第三步：上传、追问和查依据

双击启动后进入对话工作台：

1. 选择图片并点击“使用这张图片”，或使用D盘示例。
2. 保持“离线工具演示”，点击一个任务示例，再点“开始分析”。
3. 展开“查看执行过程”，观察模型响应格式、工具名称、缓存与耗时。
4. 先比较校正结果，再追问“识别校正后的那张图”，观察同一会话如何引用 corrected。
5. 问“解释为什么这个结果不能自动接受”，查看知识片段和来源。

离线模式使用真实视觉算法和本地知识检索，但工具选择由规则模拟。它可用于学习和调试，不能测出真实LLM能力。

## 接入真实大模型

将 `.env.example` 复制为 `.env`，只在本地填入你的密钥；然后重启双击启动的服务，选择“真实大模型对话”。 `.env` 已被 Git 忽略。不要把密钥放入报告或聊天。

云端只获得文字任务、结构化测量、目标框与检索片段。浏览器预览和图像数组不会发送给模型。缺密钥或网络故障会显示明确状态，没有自动的伪造回答。

## RAG 究竟做了什么

KnowledgeRetriever读取来源清单，将资料按400字分段、80字重叠，建立字符TF-IDF。收到问题后取最多3段；低于0.10默认相似度阈值的片段不返回。这是小知识库的检索基线，不是已经验证的语义检索系统。

模型选择引用编号；程序展示对应片段和来源。图像工具负责“测出了什么”，知识库提供“为什么可能这样”；知识片段不能覆盖可靠性判断。

练习：查看知识来源清单，解释为什么实验报告与官方数据说明需要分别标明来源。将问题改成与知识库无关的内容，观察 evidence_insufficient。
