# 从这里开始使用和学习

## 现在怎样打开

1. 在项目文件夹双击 **双击启动.bat**。
2. 新页面中点击 **使用D盘示例图**，也可以上传自己的图片。
3. 保持 **离线工具演示（规则调度）**。
4. 点击 **只检查这张图的曝光**，再点击 **开始分析**。
5. 查看结果，展开 **查看执行过程**。
   结果上方现在显示 **理解的任务、必要结果、任务状态**。检查图片指向是否符合你的意思；“任务已完成”与“图像质量失败”可以同时出现。
6. 再试 **比较校正前后，识别有没有改善**，然后追问 **识别校正后的那张图**。

本地地址：[对话工作台](http://127.0.0.1:7860/agent)，[原有完整分析](http://127.0.0.1:7860/)。地址需要本地服务正在运行。

首次从GitHub获取代码时，需要Python依赖和完整的Git LFS模型。建议克隆后在源码目录使用 `python -m pip install -e .`。此版本按源码项目运行，知识库和网页资源保存在仓库中，尚未制作独立安装包。

## 以后接云端

将 `.env.example` 复制为 `.env`，在自己的电脑上填写密钥，重启服务后选择真实大模型对话。页面会显示是否配置，但不会展示密钥。缺密钥时明确提示，不会把离线规则伪装成模型。

图片、热图和检测在本地计算。云端接收文字任务、测量值、候选框和知识片段。0.2.3的[小批次真实评测](reports/INDEPENDENT_EVALUATION_RESULTS.md)已完成，保留验收题尚未运行。

## 云端报错在哪里查看

分析失败时，原图上方会直接展开 **错误详情**。先看 **云端响应** 和 **失败位置**，再看具体原因、处理建议和脱敏后的模型返回片段。

| 云端响应或提示 | 含义与检查方法 |
|---|---|
| HTTP 401 / 403，账户认证 | 检查密钥是否有效、是否被撤销及账户访问权限；程序不会重复尝试认证失败 |
| HTTP 402，账户余额 | 去 DeepSeek 开放平台查看可用余额 |
| HTTP 429 / 5xx，云端API请求 | 请求限制或服务繁忙；程序最多重试一次 |
| 未收到HTTP响应，网络连接 | 检查网络、代理或证书；此时没有实际的401/402错误码 |
| HTTP 200，模型结束结果与证据校验 | 云端已返回，但结束格式或引用未通过程序校验；查看返回片段与执行记录 |
| HTTP 200，任务理解 / 任务完成校验 | 云端已返回；任务 JSON 无效，或尚未补齐并选用必要证据。查看理解的任务和具体缺项 |

网页还会分别显示 **API请求尝试次数、成功模型响应次数、工具执行次数、格式纠错次数**。请求尝试包含一次网络重试；成功模型响应表示已解析出模型消息。工具为0次时，本轮没有执行新的图像计算，缓存结果会明确标注。浏览器里 `/api/chat` 的 HTTP 200 是本地网页接口的状态；应以错误详情中的上游状态判断 DeepSeek 请求。

没有任务所需依据时，模型必须先调用工具。任务理解、格式、引用与完成缺项共用每轮最多两次结果纠错。新增一次任务理解调用，计入原有10次模型调度、12次工具及180秒预算。页面中的“结果纠错”包括格式与完成缺项纠错；达到上限会保留相关实际结果，并标为任务未完成。

后续修改 `.env` 中已加载的密钥或模型配置，需要重启项目后台服务。只关闭浏览器不会停止后台服务；重启会清空图像会话，需要重新加载图片。

本轮具体检查和边界见 [云端调度修复记录](reports/DEEPSEEK_FIX_RESULTS.md)。

## 常见情况

| 提示 | 操作 |
|---|---|
| D盘没有示例图 | 上传自己的水下图像，或按README下载到D盘 |
| 缺少完整模型 | 在项目目录获取Git LFS模型文件 |
| 校正图不存在 / 需要澄清 | 在同一会话回复“先校正原图”，再追问校正图；也可以明确改为分析原图 |
| 质量失败/不可靠 | 查看原图、校正图与原因；系统不会把失去的纹理当作恢复事实 |
| 会话过期 | 重新上传图像 |
| 启动失败或端口被占用 | 关闭之前运行的项目服务再双击启动；查看本地启动日志 |
